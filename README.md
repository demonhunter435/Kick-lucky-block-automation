# Kick-lucky-block-automation

This automation is for Roblox game call Kick a Lucky Block By No More Flops


The code contain automation for:

Perfect Kick : where the character always get perfect kick for the farthest distance. 

Auto click button for bonus training power

This automation has the ability to auto farm brainrot: where the character keep automatically kick with perfect precision, bring the brainrot back to base and repeat. (This feature require fine tune for each player specific kick power and walkspeed indicate using second.

Lastly, Player can use AutoFarm feature to automatically train with automation bonus button clicking and upgrade their specific brainrot level every minute (can be fine tune for personal preference).


This program will not have an exit key(still working on it). To exit, users can simply close the terminal or force stop IDE if use one. (ctrl + f2 for Pycharm IDE)

*IMPORTANT*
If has any trouble with the automatically click feature, users can screenshot their own image of the purple button and upload for better accuracy. Users can also fine tune the confident level when detecting the bonus button. Sometime there is display resolution issue that can be solve by upload and use personal image or the detection confident too high or low. If the confident is too high for individual users the mouse will randomly click where it think is the purple button. If confident level too low the feature might not register there is a button at all. So, fine tune some variable for personal preference.
